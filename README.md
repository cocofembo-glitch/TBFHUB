# 🔥 TBFHUB

> **Web-Portfolio & Interactive Ecosystem Showcase for TBF Projects**

TBFHUB — це веб-платформа та інтерактивний термінал для демонстрації проєктів екосистеми TBF.

---

### ⚡ Особливості (Features)

* **🖥 Interactive Terminal Shell**: Підтримка команд (`help`, `projects`, `whoami`, `clear`, `info`).
* **📦 Dynamic Projects Showcase**: Автоматичне завантаження проєктів з **Firebase Realtime Database**.
* **🔑 Admin Management**: Адмін-панель для швидкої публікації та видалення проєктів на льоту.
* **🎨 Cyberpunk / Dark UI**: Стильний дизайн у темно-неонових тонах.

---

### 🛠 Технологічний стек (Tech Stack)

* **Frontend**: HTML5, CSS3, JavaScript (ES6+)
* **Database**: Firebase Realtime Database
* **Hosting**: GitHub Pages
